01

THE 3 MODES

会話する、丸ごと任せる、作らせる。仕事の重さで使い分けます

CHAT

会話する

質問・下書き・壁打ち。やり取りを重ねて進める。ここまで3回でやってきた場所

COWORK

丸ごと任せる

目標を渡すと、計画を立てて複数の資料をまたぐ重い仕事を最後までやり切る

CODE

作らせる

ソフトウェアの構築。書いて、動かして、確認しながら仕上げる

豆知識: CoworkとCodeは同じエンジンで動いています。「任せて完走させる」仕組みが共通で、向き先が資料か、ソフトかの違いです。

02

CHAT ── デスクトップならでは ⚠️

Chatには、アプリで使うからこその4つの便利があります

クイックエントリー

キー操作ひとつで、作業中の画面の上にClaudeを呼び出せる（MacはOptionキー2回 ⚠️）。作業を中断せず質問できる

スクリーンショット共有

いま見ている画面をそのまま渡す。「この画面の数字は何を意味する？」が言葉で説明するより速い（Mac ⚠️）

音声入力

打つ代わりに話す。移動前の思いつきを吹き込んでアウトラインにさせる、が定番（Mac ⚠️）

デスクトップコネクタ

PCの中のツール（メモアプリなど）とつないで、そこにある情報を使わせる。詳しくは第7回

Mac表記の機能はWindowsでは提供状況が異なる場合があります。当日、実機で一緒に確認します ⚠️

03

COWORK ⚠️

Coworkは「重い仕事」のための設計です

フォルダごと渡せる

PCのフォルダを指定すると、中身を読み、関連を判断し、完成品を同じ場所に保存する

計画を立てて、確認してくる

始める前に範囲・形式を質問し、プランを見せながら進む。途中で方向付けできる

スケジュールタスク

毎朝の受信箱の仕分けやデイリーブリーフィングなど、繰り返し作業を自動で回す

スマホから指示（Dispatch）

外出先からモバイルアプリで、PC上のファイルやツールを使うタスクを任せられる

守られた作業場

共有したフォルダの中だけで動く隔離された空間。それ以外の場所には触れない

ほかにブラウザ操作・プラグインなどの拡張もあります。本格的に触るのは第10回。今日は講師の実演で「任せるとどうなるか」を見ます。

04

CODE ⚠️

Codeは「動くもの」を作る場所。手綱は3段階で握れます

何ができるか

コードを書き、実行し、結果を確かめながらソフトを仕上げる。変更は差分で見え、履歴が残るのでいつでも戻せる。作業場所はPC内（ローカル）とクラウド（リモート）を選べる

自動で進む範囲を選べる

Ask＝全部確認を待つ／Code＝ファイル変更は自動、コマンドは確認／Plan＝着手前に計画を見せる。初心者はAskとPlanが安全弁

経営者にとってのCodeは「プログラミングを学ぶ場所」ではなく、小さな業務ツールを日本語で発注する窓口です。第11回で、実際に1本作る体験をします。

05

WHICH MODE?

選び方は「仕事の重さ」。この3行だけ覚えれば足ります

モード最適な用途（公式の整理）見分けるひと言
Chat速いやり取り。アイデア検討・下書き・素早い回答「ちょっと聞きたい・書きたい」
Cowork複雑または継続的な作業。調査・分析・ファイル整理・完成した文書づくり「資料が多い・時間がかかる・毎回やってる」
Codeソフトウェアの構築。記述・テスト・実行・公開「動く仕組みがほしい」

迷ったらChatで始めて構いません。会話が「これ、毎回やってるな」「資料が多すぎるな」となった瞬間が、Coworkへ引っ越すサインです。
